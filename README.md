# Contributing to CristianNichifor projects

Shared defaults for public open-source projects. Repository-specific contribution and security files take precedence.

Start with the project's README, CONTRIBUTING and AGENTS files. Each repository owns its license, setup, domain rules and verification commands. These defaults are displayed by GitHub but are not copied into other repositories' clones.

Changes here are proposed through PRs; the maintainer reviews and merges. Do not add private infrastructure details or credentials.
