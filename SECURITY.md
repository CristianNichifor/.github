# Security

Please do not disclose credentials, personal records, or an exploitable vulnerability in a public issue.

Use the repository's Security tab to report a vulnerability privately when private reporting is enabled. Otherwise contact the maintainer at cristian@cristian-nichifor.com. Include the repository, affected revision, minimal reproduction and impact; use synthetic data.

Support and fix availability depend on each project's maintained versions. Historical demos and forks may direct fixes to their maintained or upstream repository. This policy does not promise a response deadline.
